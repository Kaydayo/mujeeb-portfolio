# Mujeeb Adebowale — portfolio

My personal portfolio. I'm a senior software engineer in Lagos, working on card issuing and payments.

The site opens like a terminal session and then shows a hologram of me. Scroll down to find:

- **About:** who I am and where I've worked
- **Experience:** my roles and what I shipped in each one
- **Case files:** a few hard problems I've solved
- **Skills:** the tools I work with
- **Builds:** two products I build outside my day job, including [Peguin](https://www.peguin.co)
- **On record:** education, training and certificates
- **Contact:** how to reach me

Built with TypeScript, Three.js and a little Rust.
